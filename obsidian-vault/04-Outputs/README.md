# Natijalar

Codex tayyorlagan tadqiqotlar, savol-javoblar, taqqoslashlar va slayd matnlari shu papkada saqlanadi.

Har bir natija:

- savol yoki maqsadni;
- qisqa xulosani;
- asosiy dalillarni;
- foydalanilgan ichki qaydlar havolasini;
- noaniqliklar va keyingi savollarni o'z ichiga olishi kerak.
